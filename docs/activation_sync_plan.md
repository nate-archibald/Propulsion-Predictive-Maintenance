## Per-candidate CDF notes

- **All 13 candidates:** source has `delta.enableChangeDataFeed = true` **already set** (verified via
  `databricks tables list`). Step 33 must **NOT** re-enable CDF — it is a no-op and can error on MANAGED tables.
- **No "CDF not applicable" rows:** there are no Metric Views, TVFs, or Iceberg sources in this plan,
  so no SNAPSHOT-only / non-Delta candidates exist.
